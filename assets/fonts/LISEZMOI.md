# Polices

Déposez ici les 3 fichiers de la famille **Zeitung Pro** (avec exactement ces noms) :

- `ZeitungPro-Regular.otf`
- `ZeitungPro-Semibold.otf`
- `ZeitungPro-Bold.otf`

(`.ttf` accepté aussi.)

⚠️ Zeitung Pro est une police commerciale : si le dépôt GitHub est **public**, ces fichiers
seront téléchargeables par tout le monde. Dans ce cas, préférez le bouton **Ressources → Charger…**
de l'application : les polices restent alors uniquement dans votre navigateur.

Sans ces polices, l'application utilise Helvetica en secours.
